# 1. FINALIDAD

Este documento define la estructura que deberán seguir las once unidades didácticas del módulo.

Su objetivo es conseguir que todo el curso tenga:

```text
misma organización

misma terminología

misma jerarquía visual

mismo sistema de actividades

mismo sistema de evidencias

mismo formato de prácticas

mismo formato de rúbricas

misma separación alumno/profesor

misma lógica de cierre
```

A partir de este momento:

# NINGUNA UD SE MAQUETARÁ CON UNA ESTRUCTURA DIFERENTE SIN JUSTIFICACIÓN.

---

# 2. PRINCIPIO GENERAL DE DISEÑO

El material debe poder utilizarse:

```text
como apuntes

como guía de clase

como material de estudio

como manual de prácticas

como referencia para recuperar

como evidencia de programación docente
```

Por tanto, cada UD debe ser:

```text
autosuficiente

ordenada

visual

progresiva

práctica

trazable

evaluativamente inequívoca.
```

# 17. FORMATO DE CÓDIGO

```text

```

---

# 18. COMENTARIOS EN CÓDIGO

Solo utilizar comentarios cuando:

```text
aporten explicación didáctica.
```

Evitar:

```java
// suma uno
contador++;
```

Preferir:

```java
// Simulamos un valor incorrecto
// para estudiar el comportamiento
precio = -1;
```

cuando sea pedagógicamente relevante.

---

```text

paso 3

resultado final.
```
