# 19. CONDICIÓN INTERNA PARA CALCULAR UN RA

Un RA tendrá:

```text
NOTA DEFINITIVA
```

```text

```

```text

```

# 20. SUPERACIÓN INTERNA DEL RA

Decisión de programación:

```text
RA superado
si:

1. todos sus CE tienen evidencia

y

2. nota media del RA >= 5,00.
```

---

# 21. COMPENSACIÓN INTERNA DE CE

Dentro de un mismo RA podrá existir:

```text
CE < 5
```

pero quedar en estado:

```text
C
```

si:

```text
todos los CE tienen evidencia

y

media del RA >= 5,00.
```

La nota numérica original del CE:

# NO SE ALTERA.

Ejemplo:

```text
RA =

CE a = 7
CE b = 6
CE c = 4
CE d = 7

media = 6

→ RA superado

CE c:
4,00 — C
```

---
